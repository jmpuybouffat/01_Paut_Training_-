🇫🇷 Étapes

  1. Ouvrir Streamlit Community Cloud et se connecter.
  2. Choisir Create app, depuis GitHub, puis copier les valeurs du tableau.
  3. Si l’option est proposée dans Advanced settings, choisir Python 3.12, testé pour cette application. Les dépendances sont à la racine du dépôt.
  4. Cliquer Deploy et attendre le démarrage.
  5. Vérifier la présence des boutons Manuel français · PDF et English user manual · PDF, puis l’application prototype P03.
  6. Mode MWB → Position témoin → vérifier X65 / Y105,125 / orientation90° / TOP / 45° ; lire l’A-scan et son écho vers15,3 µs.
  7. Télécharger un manuel et vérifier que le palpage en cours n’a pas été réinitialisé. Essayer le drapeau anglais, puis revenir au français.
  8. Conserver l’URL réellement générée par Streamlit et la communiquer aux relecteurs choisis.

🇬🇧 Steps

  1. Open Streamlit Community Cloud and sign in.
  2. Choose Create app from GitHub; copy the table values.
  3. If offered under Advanced settings, choose locally tested Python3.12. Dependencies are at repository root.
  4. Select Deploy and wait for startup.
  5. Check both PDF manual buttons and prototype P03.
  6. MWB → Witness pose: X65 / Y105.125 / heading90° / TOP / 45°; inspect the A-scan near15.3 µs.
  7. Download a manual and check that scanning was not reset. Test the English flag, then return to French.
  8. Record the actual generated service URL and share with the selected reviewers.
